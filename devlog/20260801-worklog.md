# Worklog — first shot, built and deployed (Claude / Fable 5)

Note on models, for the record: this entire session — including the design
entries in this devlog — ran on **Claude Fable 5** (the session was switched
to it at the start). The *runtime* extraction LLM is a separate thing: local
ollama `gpt-oss:120b` did the comparison run; the Anthropic path now defaults
to `claude-fable-5` (with server-side fallback to Opus on safety declines)
whenever an `ANTHROPIC_API_KEY` is present. No key is set on this box yet, so
the Anthropic path is dormant; the frontier extractions in
`data/reference-extractions.json` were authored by Fable in-session.

## What was built (one day)

- **Model**: single `entities` collection; ECS components; prototype-based
  classification (prototypes are entities, open hierarchy); **relations are
  entities** carrying provenance/confidence — the resolution of the
  "separate table or property?" question (see 20260801-design.md).
- **Pipeline** (`server/`): Driftwood feed ingest → HTML→text → LLM extraction
  (strict-JSON prompt, quotes required) → resolve/dedupe (canonical name +
  aliases + `nomic-embed-text` cosine ≥0.86; `FUZZY_MERGE=0` for
  deterministic runs) → prototype + component discovery → `graph.json`
  snapshot. `run.js --watch N` = persistent worker on this box; `fold-file.js`
  folds saved extraction sets through the same resolver.
- **Data**: 10 real articles fetched; frontier reference extractions folded →
  **71 entities, 53 relations, 17 prototypes**; cross-article dedup verified
  (Driftwood ×3, CRD ×2, Waterworks ×2 as single nodes). Hand gazetteer
  geocodes 20 entities.
- **Viz** (`app/`): d3-force graph — instances coloured by prototype, sized by
  degree+mentions, prototype hubs with dashed is-a links, hover edge labels,
  drag/zoom, layout pre-warmed with synchronous ticks (robust to rAF
  throttling); maplibre island map (CARTO dark, perimeter from the saltspring
  demo); enumerations (prototypes / component buckets / entities); provenance
  detail panel; detailed About page (`?about=1`, `?view=map` deep links).
- **Comparison run**: gpt-oss:120b vs the frontier reference on 3 articles —
  see 20260801-model-comparison.md. Local model: higher recall, noisier
  prototypes, ~3 min/article.
- **Deployed**: https://ssontology.exe.xyz (VM `ssontology`), push-to-deploy
  installed (repo `orbitalfoundation/saltspring-ontology`; first setup pass
  404'd on a wrong repo name, fixed).

## Gotchas hit

- Svelte 5 `$effect` loop: rebuilding the d3 node array inside an effect that
  also read it → infinite loop. Fix: `$state.raw` + `untrack` + depend only on
  the filter.
- SVG `clientWidth` is 0 — measure with `getBoundingClientRect`.
- Headless Chrome throttles rAF, so a force layout never settles in
  screenshots → pre-warm the simulation with `sim.tick()` ×320 synchronously
  (also gives users an instant stable layout).
- gpt-oss:120b cold load is ~2.5 min (78.8 GB into VRAM); warm inference
  ~170–260 s/article at `num_ctx 8192`.
- Driftwood feed `<link>` URL filter off-by-one initially returned zero
  articles.
